Feature 1: Three.js Background Canvas
Create ONE Three.js renderer for the background. Attach it to a <canvas id="bg-canvas"> with this CSS:
css#bg-canvas {
  position: fixed;
  top: 0; left: 0;
  width: 100%; height: 100%;
  z-index: 0;
  pointer-events: none;
}
All page sections must have position: relative; z-index: 1 so they appear above the canvas.
Scene contents:

Floating panels — 20 PlaneGeometry(2, 2.6) meshes placed at random x/y positions and z between -8 and -25. Use MeshBasicMaterial({ color: 0x7C3AED, transparent: true, opacity: between 0.03 and 0.07, side: THREE.DoubleSide }). Give each a random initial rotation. In the animation loop, oscillate each panel's y position with Math.sin(time * speed + offset) * 0.3 and slowly increment rotation.z by a tiny amount each frame.
Particle field — Create a BufferGeometry with 1000 vertices scattered randomly across x: -15 to 15, y: -10 to 10, z: -5 to -20. Use PointsMaterial({ color: 0xffffff, size: 0.05, transparent: true, opacity: 0.4 }). In animation loop, move each particle's y up by 0.002 per frame; if y > 10 reset to y = -10.
Mouse parallax — Track mousemove on the document. In animation loop, lerp camera.position.x toward mouseX * 0.5 and camera.position.y toward -mouseY * 0.5 with factor 0.02.
Scroll camera pull — In the animation loop, read window.scrollY and set camera.position.z = 5 + scrollY * 0.003 (clamped to max 9).
Performance — Use a delta-time check: only call renderer.render() if at least 33ms have passed since last render (30fps cap). On mobile (window.innerWidth < 768), create only 8 panels and 300 particles.

Camera: PerspectiveCamera(75, aspect, 0.1, 100), position z = 5. Renderer: { alpha: true, antialias: false }, setClearColor(0x000000, 0).

Coverflow Positioning (recalculate every frame based on currentIndex float)
For each card at index i, compute offset = i - currentIndex. Then:
card.position.x = offset * 2.4
card.position.z = -Math.abs(offset) * 1.2
card.rotation.y = -offset * 0.45  (clamp to ±0.9)
card.scale.setScalar(offset === 0 ? 1.0 : Math.max(0.65, 1 - Math.abs(offset) * 0.12))
Center card (abs(offset) < 0.5): add a purple EdgesGeometry outline mesh as a child, scale it to 1.01x so it frames the card. Remove/hide outline on non-center cards.
Drag Interaction
jslet isDragging = false, dragStartX = 0, dragDelta = 0, velocity = 0;

canvas.addEventListener('mousedown', e => { isDragging = true; dragStartX = e.clientX; velocity = 0; });
window.addEventListener('mousemove', e => {
  if (!isDragging) return;
  dragDelta = (dragStartX - e.clientX) / 200;
  currentIndex += dragDelta * 0.08;
  currentIndex = Math.max(0, Math.min(artworks.length - 1, currentIndex));
  dragStartX = e.clientX;
  velocity = dragDelta;
});
window.addEventListener('mouseup', () => { isDragging = false; });
// Touch equivalents: touchstart/touchmove/touchend using e.touches[0].clientX
In the animation loop, when not dragging: apply inertia (currentIndex += velocity; velocity *= 0.92), then when Math.abs(velocity) < 0.001 snap to Math.round(currentIndex) using lerp: currentIndex += (Math.round(currentIndex) - currentIndex) * 0.08.
Auto-rotate
Start a timer on idle. After 3 seconds of no interaction, increment currentIndex by 0.005 per frame (wraps 0 → 6). Reset timer on any mousedown/touchstart.

Do not use any import or require statements — only CDN scripts loaded via <script src>
The two Three.js renderers (background + carousel) must use separate renderer instances with separate canvases. Do not share a renderer.
