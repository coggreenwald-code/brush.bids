Completely redesign the BrushBids homepage as a bold, modern, interactive student art auction website with a cool blue/purple/gray palette and an immersive scroll-driven hero that zooms from a satellite view of The Metropolitan Museum of Art into an interactive 3D gallery wall showcasing featured auction pieces.
This should feel like a premium gallery experience — not a generic marketplace. The page needs to make visitors think "this is legit" within 2 seconds.

TECH STACK

React + TypeScript (already in the project)
Tailwind CSS for utility styling
Framer Motion for scroll animations and transitions (npm install framer-motion)
Three.js + @react-three/fiber + @react-three/drei for the 3D gallery wall (npm install three @react-three/fiber @react-three/drei)
GSAP + ScrollTrigger for the scroll-pinned hero image sequence (npm install gsap)
Use existing project structure — update the homepage component only. Do NOT touch backend or API routes.

PHASE 2: Interactive 3D gallery wall (@react-three/fiber)
Once scroll sequence completes, unpin and reveal a full-width 3D gallery:
Scene:

Camera facing a museum wall (large plane, MeshStandardMaterial, color #e8e8f0, roughness 0.9)
5 paintings in asymmetric museum-style arrangement:

1 large center painting (40% wall width)
2 medium flanking (offset above-left and below-right)
2 smaller at far edges


Frame material: dark slate, MeshStandardMaterial, roughness 0.5, metalness 0.3, color #2a2a3a
Canvas textures: Unsplash artwork images via useTexture from drei
Lighting: ambient (0.4) + 2 spotlights angled down (0.8), soft shadows
Optional polished floor: dark reflective plane, color #0a0a14, roughness 0.2

Interactivity:

Mouse move: subtle camera sway (plus/minus 2 degrees), damped with lerp. NOT OrbitControls
Hover on painting: painting pops forward (translateZ +0.3, 0.3s ease), purple glow appears behind frame, HTML overlay fades in below showing:

Artist name (DM Sans 500, 14px, white)
Title (DM Serif Display italic, 18px, white)
Current bid (Bebas Neue, 24px, --accent2)
"Place Bid" button (small, --accent bg, white text)


Hover off: painting slides back, overlay fades out
Use drei Html component for overlays to track 3D position

Height: approximately 80vh. Use Suspense with a loading fallback (pulsing BrushBids logo).
Mobile (under 768px): replace entire 3D scene with a static grid of 5 artwork cards with the same info. Do NOT render Three.js on mobile.
